# NewsBridge Frontend

Modern, reading-first web interface for global news in regional languages.

## Features

- 🌍 Bilingual support (English & Odia)
- 📖 Reading depth selector (30/111/250 words)
- 📱 Responsive design (mobile & desktop)
- ⚡ Article navigation with swipe gestures
- 🎨 Eye-soothing color scheme
- ♿ Accessibility-first design

## Tech Stack

- Next.js 16 (React framework)
- TypeScript
- Tailwind CSS v4
- next-intl (internationalization)
- Framer Motion (animations)

## Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

## Development

```bash
# Run dev server (opens at http://localhost:3000)
npm run dev

# Lint code
npm run lint
```
