# Soul of the Project

Why does this exist?

Because millions of people can access local news in their language
but cannot easily access global knowledge.

This project exists to bridge that gap.

The goal is not direct translation. It would be meanigful translation. Should read the news from API endpoint,RSS feeds and any other legit source, no webscrapping. Then use AI model to translate it with meanigful information so that users can consume it.

The goal is understanding.

Every article should answer:

1. What happened?
2. Why does it matter?
3. Why should I care?

If a feature does not improve understanding,
it probably should not be built.

We optimize for:

- Clarity
- Trust
- Simplicity
- Accessibility

We do not optimize for:

- Clickbait
- Doomscrolling
- Addiction
- Engagement hacking
