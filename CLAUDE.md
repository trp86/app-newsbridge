# Project Instructions

Project:
Global Knowledge Brief

Mission:
Deliver global knowledge in regional languages.

Core Philosophy:
Content quality over features.

Current Phase:
Phase 1 MVP.

Tech Stack:
- Python 3.12
- uv
- pydantic
- feedparser
- OpenRouter
- Telegram

Coding Rules:
- Strong typing everywhere.
- Use Pydantic models.
- No hardcoded secrets.
- Tests mandatory.
- Use structured logging.
- Small functions.
- Avoid classes unless necessary.

Out of Scope:
- Mobile app
- Database
- Authentication
- User management

Success Metric:
Users read daily brief consistently.

When making changes:
1. Update tests.
2. Update documentation.
3. Update TODO.md.
4. Update DECISIONS.md if architecture changes.
